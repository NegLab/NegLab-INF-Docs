Are there reliable individual differences in negation processing?

Code & archive

About this project

This collaboration investigates individual differences in negation processing and their relationship with domain-general cognitive abilities, including inhibitory control, working memory, and cognitive flexibility. Using data from multiple behavioral experiments, the project examines the reliability of cognitive and language-processing measures and evaluates whether individual differences in cognitive abilities predict variability in negation processing. The collaboration is expected to contribute to a joint research publication.
