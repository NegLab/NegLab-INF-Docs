RT-SEG

A toolkit for reasoning trace segmentation

Maintained by Leon Hammerla

Developed by Leon Hammerla, Bhuvanesh Verma, Alexander Mehler

Software

Open tool Documentation Code & archive

About this tool

RT-SEG is a modular toolkit for segmenting reasoning traces into coherent units and optionally assigning labels to the resulting segments. It provides rule-based, probabilistic, semantic, and LLM-based segmentation engines together with strategies for combining segment boundaries from multiple engines.
