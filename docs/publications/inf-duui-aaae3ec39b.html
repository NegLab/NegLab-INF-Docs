Docker Unified UIMA Interface

Scalable and distributed NLP processing with reusable microservices

Maintained by Text Technology Lab

Developed by Giuseppe Abrami, Markos Genios, Filip Fitzermann, Daniel Baumartz, Alexander Mehler

Software

Open tool Documentation Code & archive

About this tool

Docker Unified UIMA Interface (DUUI) provides a scalable, platform-independent framework for constructing and executing NLP pipelines from reusable microservice-based components. It supports distributed corpus processing and the integration of heterogeneous NLP tools using technologies such as Docker and Kubernetes.
